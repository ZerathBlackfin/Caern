# Icons

The `icon` of a tile can be:

- a [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons) name, like `sonarr`. The PNG version is used by default; add `.svg`, `.png` or `.webp` to pick the format.
- a file from `/config/icons`, like `/icons/nas.png`
- a URL

Without an icon, or if it fails to load, the tile shows the first letter of its name.
